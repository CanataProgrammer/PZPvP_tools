# CZPvP Results (GitHub Pages)

CZPvP_tools の大会結果サイトです。Mod のプログラムは `main` ブランチ、このサイトは `gh-pages` ブランチで管理しています。

- 公開URL: https://canataprogrammer.github.io/PZPvP_tools/
- 大会の追加: サイトの「Tools」で Mod の CSV(ワールドフォルダの `czpvp_results/`)から大会ファイルを作り、
  `data/tournaments/<ID>.json` と `data/index.json` を置いてコミット・push する。
